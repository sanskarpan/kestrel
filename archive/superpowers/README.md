# Archive: agent working material

This directory holds the per-phase design docs (`specs/`) and implementation
plans (`plans/`) produced while building Kestrel. It is **read-only
historical context** — preserved for auditability, not a pattern to extend
and not part of the published docs site.

Canonical references:

- `SPEC.md` — architecture and behavioral requirements
- `CHECKLIST.md` — 328-task completion record
- `docs/` — user guide, FAQ, benchmarks, and per-subsystem docs
- `docs/EXPLAIN.md`, `docs/STRETCH.md` — curated explain/stretch notes
